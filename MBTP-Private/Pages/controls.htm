  • # The program uses this field to try to find the roots of affixed words.

  • # The four types of fields are:
  • #   p = prefix

  • #       s = s           for most cases, e.g., cats
  • #       s = es          for some cases, e.g., misses

  • #       s = ice +ouse   for mice, lice, etc.

  • #       (without the quotes and separated just by spaces)
  • #   or it can contain the single value NONE for none, or ALL for all of the above

  • #       s = s           for most cases, e.g., cats
  • #       s = es          for some cases, e.g., misses

  • # This special field AllowedAffixCombinations is for affix combinations
