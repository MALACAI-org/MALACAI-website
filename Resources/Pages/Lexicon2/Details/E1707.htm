light1
/lite/
 
n-uc.
 
1.
Def.: layag
MS: layag
the brightness which helps us to see things.
If there is a full moon, there is a lot of light at night.
 
adj.
 
2.
Def.: malayag
MS: malayag
If a place is light, there is brightness there, so that you can see.
It's only 5pm, so it's still light.
There were many lamps, so the room was quite light.
 
n-ct.
 
3.
Def.: sulù
MS: sulù
something such as a lamp or candle, which you can use to see in a dark place.
 
vt.
 
4.
Def.: egsilab
MS: egsilab
When you light something which can burn (e.g., a fire, a match, a candle), you cause it to start burning.
 
n-ct.
 
5.
Def.: nateil ne peg-agseb (meyitenged te minsan nekey)
MS: peg-agseb
If you see something in a particular light, you have a particular opinion about it.
At first I didn't like him much, but as I came to know him better I began to see him in a different light.
Te hun-a kena a egkeupian kandin, piru te neila kud amana sikandin migbunsud a mig-agseb te lein-lein diyè te kandin.
 
adj.
 
6.
Def.: makalawag
Note: how about maangkaag too?
MS: makalawag
If a colour is light, it is pale, not strong or dark (e.g., light blue).
Irreg. v.  lit, lit.
Source: GSL0201-0225
