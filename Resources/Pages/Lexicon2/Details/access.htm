access
/æk-sess/
 
vt.
 
1.
Def.: eg-angey
MS: eg-angey
If you access something such as information, you get it.
Somebody accessed my file and changed something.
Due mig-angey te pepilis ku wey migliwanan ka duma.
 
n-uc.
 
2.
Def.: pegpekeendiyè [egpeke͡endiyè] wey pegkahamit te minsan nekey
MS: pegpekeendiyè; pegkahamit
the fact that you can go to a place or use a thing (have access to something).
I have access to a computer, so I can check email.
Egpekeendiyè [egpeke͡endiyè] wey egpakahamit a te kumpyutir, sika ka egpakapitew a te imil ku.
Sem.Dom.: AWL4
 
 
accessible
/æk-sess-ə-bəl/
 
adj.
Def.: kaayunan
MS: kaayunan
If a place is accessible, you can go there. If a thing is accessible, you can get it.
That village is not accessible by truck, only by walking.
Status: ready
