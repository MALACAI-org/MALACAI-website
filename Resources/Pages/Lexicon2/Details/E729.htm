create
/kree-yate/
 
vt.
Def.: eggimu
MS: eggimu
If you create something new, you cause it to exist.
Walt Disney created Mickey Mouse.
Source: AWL1
 
 
creation
/kree-yay-shən/
 
n-uc.
Def.: peggimu
MS: peggimu
the action of creating something.
The Bible teaches about the creation of the world.
Ka bibliya egpanulù meyitenged te peggimu te kalibutan.
The purpose of this new government project is the creation of 500 new jobs.
 
n-ct.
Def.: hinimuwan
MS: hinimuwan
something which has been created.
Mickey Mouse is a creation of Walt Disney.
Ka Mickey Mouse hinimuwan ni Walt Disney.
