bangbang
/baŋbaŋ/
 
n.
a cut in a tree
Eng. cut in a tree, a; notch in a tree, a; tree, a cut in a
Online dict status: -
Usage level: R
 
v.
for someone (egbangbang, migbangbang/imbangbang, agent, eg><ø-) to make cuts in a tree (e.g., a coconut tree) (egbangbangen, imbangbang/migbangbang/pigbangbang, egbangbangan, imbangbangan/migbangbangan/pigbangbangan, location, eg><en-, eg><an-) using an axe or bolo (igbangbang, imbangbang, instrument, ig><ø-)
Egbangbangan ku pad ka niyug su egpamaneyik a.
I will make cuts in the coconut tree because I am going to climb.
Cult. This can be done in order to climb the tree.
Eng. cut notches, to; cuts in wood, make; tree, make cuts in a

Usage level: R
